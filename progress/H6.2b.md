# H6.2b - listing sub-category

## Done
- Listing model: `subcategoryId` (ObjectId, indexed) in schema and `ListingDoc`. Public/owner view returns it.
- service: `createDraft` (the "createListing" step) and `applyBasics` save `subcategoryId`. It must belong to the chosen category and be visible, else a validation error. Required when the category has visible sub-categories (on create, and on a basics update that sends a category or sub-category). Changing category drops the old sub-category. Title-only edits of old listings are unaffected.
- CSV import: new `subcategory` column via `resolveSubcategory`. Unknown value = error row. Blank on a category with sub-categories = error row.
- UI-text key `listing.hub.browseBySub` = "Browse by type" added to `src/lib/ui/text.ts`.
- `src/server/seo/templates.ts`: page type `subcategory` accepted; `subcategoryCopy()` returns template copy (category-specific wins field by field) with the built-in copy as fallback. `{category}` is filled with the sub-category name.
- `src/server/seo/subcategory-sitemap.ts`: `subcategorySitemapEntries(toLoc)` lists only hubs with 5+ active ads (via `indexableSubcategoryHubs` and `placePath`).
- `src/server/models/catalog.ts`: left alone. Categories have no icon field and no UI uses one; only sub-categories have icon.
