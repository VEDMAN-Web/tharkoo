# H6.4 On-site chat ("Chat now")

Branch: haiku/h6.4-chat. Based on `haiku/h6.0-ownership` (PR #95) because #95 was not merged when this started; H6.3 (PR #99) was also not merged yet. Rebase onto main once both land.

## Done
- Models: `Conversation` (listing, buyer, seller, lastMessageAt, blocked, plus report flags) in `src/server/models/conversation.ts`, indexes (seller, lastMessageAt), (buyer, lastMessageAt), unique (listing, buyer). `ChatMessage` (conversation, sender, text, imageUrl, createdAt, readAt, deletedAt) in `src/server/models/message-chat.ts`, index (conversation, createdAt). It is called `ChatMessage` because an older unused `Message` model already holds the name.
- Service `src/server/chat/service.ts`: start (one conversation per buyer and ad, not your own ad, ad must be live), send, list with `after` cursor (read receipts), inbox with unread counts, unread total, block, report.
- Text is stripped of tags, at most 1000 chars. Photos: jpeg/png/webp, at most 5 MB, magic bytes checked, stored through the same adapter as ad photos (`src/server/chat/image.ts`: Cloudinary `tharkoo/chat/` when configured, else `public/uploads` served by the existing `/uploads/[file]` route). A photo is stored only after the participant, block and rate-limit checks pass.
- Rate limit: 30 messages per 10 minutes per user, counted from stored messages (works across serverless instances).
- Safety: Report and Block in every conversation. A blocked conversation rejects sends from both sides. Reporting flags the conversation; staff can read ONLY a reported conversation (audited `chat.admin_read`) and delete messages in it (audited `chat.message_delete`, text and image cleared). Other party's phone or email is never returned (test checks the JSON).
- API `src/app/api/chat/[[...slug]]/route.ts`: conversations (GET/POST), `unread`, `conversations/:id/messages` (GET with `after`, POST JSON or multipart with photo), `block`, `report`, and staff routes `admin/reported`, `admin/conversations/:id`, `admin/messages/:id` (DELETE). Origin check as the media route; signed-out gets 401.
- UI (`src/components/chat/`): `ChatNow` (button, sign-in prompt for signed-out, bottom-sheet panel max 480 px wide, Esc closes), `ChatThread` (polls every 5 s while open and the tab is visible), `Inbox`, `UnreadBadge`. Gold theme tokens only.
- Ad page (`src/app/ad/[slug]/page.tsx`): a "Chat now" block under the ad. Messages inbox at `/u/account/messages/`. Dashboard page shows a Messages button with the unread count.

## Risks
- Polling is every 5 s per open panel; the inbox refreshes every 15 s and the unread badge every 30 s.
- A new model name `ChatMessage` differs from the card's "Message" wording (name clash).
- Conversations are listing-scoped; when an ad expires the chat history stays readable but new chats cannot start (the ad must be active).
