# H3.4 — Home page from blocks (renderer, defaults, seed, preview)

**Result:** DONE for the rendering side. The admin editor is a separate branch (`haiku/h3.4-editor`, see `progress/H3.4-editor.md`). Branch `haiku/h3.4-render`.

## Done
- New block components (same markup and `tk-` classes as the built-in page): `hero` (heading is the page h1; the primary link is the post-ad button), `categoryGrid` (category cards with city pills, 2 to 6 columns on wide screens, optional ad counts), `cityLinks`, `latestAds`, `featuredAds`. Registered in `BlockRenderer`. `richText` can become the page h1.
- `src/server/layout/defaults/home.ts`: today's hero, category cards and SEO intro written as blocks. `categoryGrid` items got an optional `citySlugs` (the cards already had city picks).
- `src/server/seed/layouts.ts` (`seedHomeLayout`): publishes the current home page as `home/default` version 1 if no layout exists; safe to run twice. Called from `runSeed` and the first time an admin opens the home editor (`loadLayout`).
- `src/app/page.tsx`: renders from the published layout when there is one, otherwise the built-in page as before (also if the layout cannot be read; it logs the error). H1: the hero heading; with no hero the first titled `richText`; with neither, a visually hidden h1.
- Publish now also asks Next to refresh its cached pages (`revalidatePath`), so a publish is live within seconds instead of waiting for the 60 s page cache.
- `/admin/homepage/preview/`: the saved draft rendered like the home page (staff only; shown by the editor's Preview button).
