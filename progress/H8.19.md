# H8.19 (A19): retire the old Home writers

## Done
- `/admin/homepage` no longer edits the Home page. It shows a note with a link to the Page builder, a read-only summary (banner headline, picture description, number of categories) and keeps the three things the builder does not own: the Home title and description for search engines, the listing photo band switch and the sign-in picture. The old block editor, banner section and category count field are gone, with the old `/admin/homepage/preview/` page and `SiteContentForm.tsx`.
- Old writers refused with "The Home page banner, cards and number of categories are edited in the Page builder now. Open Page builder, then Home." (`applyHomepageChange` refuses a change to the hero, cards or category count, and refuses a reset). `applyHomeBanner`, `applyHomeCategoriesCount` and their two actions are removed. Login picture, listing band and Home SEO still save through the same path.
- Menus: the Home trust pills and How it works steps are read-only text with a link to the Page builder. Category photos are unchanged.
- `seedHomeLayout` now seeds a format 2 home (version 1, revision format 2) from the same blocks as D1. It still does nothing when a layout exists. The old editor no longer seeds the Home layout; the post-ad editor still seeds its own.
- Links that pointed to the retired screen now point to the Page builder: the launch checklist banner row, the SEO "Edit home page blocks" link, the SEO pages table and the CMS page text.
- Specs: `admin-home.e2e.ts` (old block editor) is deleted; three tests that used the old fields (number of categories, headline in the picture, hero editor help) are removed from h7-104-home, h7-105-brand and home-hero; the new `a19-home-writers.e2e.ts` covers the read-only screens and the same two settings in the Page builder (switch on, then back off).

## Not done
- The Home SEO title and description, listing band switch and sign-in picture stay on `/admin/homepage` because no other screen owns them yet.
- `homeDefaultBlocks` (old format 1 defaults) stays in the code; tests still use it to make an old layout.
