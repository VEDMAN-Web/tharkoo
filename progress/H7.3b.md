## Done

### PR 1: post-ad chips and max picks
- Pick-one and pick-many fields render as chips on the post-ad form (`PickGroup`). Search box above 20 options, first 40 chips drawn, "N of M matches" note, "Pick up to N · K picked" counter, chips disabled at the limit.
- Pure helpers in `src/lib/ui/pick-options.ts` (tested).
- Answers: pick-many is an array, pick-one a string. Empty answers are not sent.
- Server enforces the limit and the admin list in four places: listing details save (`applyDetails`), submit (`submitListing`), admin create (`checkAttributes`), import (`attributesFor`). `choiceProblems` checks drafts; zod checks submit.
- `withPickLimits` merges each field's limit from `category_field_settings`. `pickLimitsByCategory` feeds `publicCategories`, so the post-ad form gets `maxPicks` per field.

### PR 2: SEO and hubs
- Any filter parameter (`q`, `f.*`, `photos`, `verified`, state, city, area) makes a category, city or area page `noindex, follow`. The canonical is always the clean page. Pagination (`page`) is not a filter and stays on unfiltered pages.
- `withUrlSeo` now keeps a canonical passed in by the caller.
- Sub-category hubs and tag pages are `noindex, follow` (not one of the three indexable types).
- Sitemap shards: `tags` removed. The districts shard keeps only category+city+area pages; sub-category entries removed.
- Areas hub: `/cities/<city>/` lists the city's areas with links to live categories. Indexable, not in the sitemap.
- `N ads` count row removed from the listing header.

## NEED / decisions for Opus

- Sub-category hubs were indexable and in the sitemap (`subcategory-shard.test.ts`). This lane follows "only category, category+city and category+city+area". The test now asserts they are excluded. Reverse if the sub-hub design was intended.
- The category page now reads `searchParams`, so it is dynamic (no longer ISR at 300 s). The city and area pages already were. Robots come from the page metadata, not a response header.
- Robots.txt is unchanged. Filter URLs must stay crawlable so their `noindex` is seen.
- Promoted landing pages (item 5) would be the one exception to the three-type rule: they need a decision on sitemap inclusion.

## Risks

- Category documents keep the option mirror (H7.3). The pick limit is read from `category_field_settings` on each save and from a 30 s cache for the public list. Changing a limit takes up to 30 s to reach the post-ad form.
- Removing an option or lowering a limit does not change listings already saved. Their next details save or submit is checked against the new limit.
