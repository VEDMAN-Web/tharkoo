# H8.41 (A41): post-ad blocks and the Post-ad tab

## Done
- Three new post blocks, texts only: `idCheckFirst` (screen before step 1), `payStep` (the Pay and publish card and credits box) and `consent` (the terms and age lines). Every field is empty by default, and empty means "use the site text"; the field shows the site text in grey. Each field maps to an existing `post.*` key (`POST_BLOCK_TEXT_KEYS` in `copy.ts`), so no new words and no new keys. The fee, balance and plans still come from code and settings.
- `buildPostCopy` reads the three blocks into `copy.texts`; the post-ad page lays them over the site texts (block first), so the ID-check screen, the pay card and the consent lines read them through the same `useT()` as before. A hidden block adds nothing.
- `{fee}`: the page reads the posting fee from the money settings (`effectivePostingFee`, 0 while posting is free) and fills `{fee}` ("30 credits") in every block text (steps, intro, plan note, success) with `fillCopyFee`, and in every `post.*` site text through a shared value on `UiTextProvider` (`makeT(texts, shared)`).
- Page builder, Post-ad tab (`_post/**`): block list with the six steps always on (only the plan step can be hidden), Show/Hide for the other parts, Add part for a missing one, a field set for every part (steps, intro with picture, photo rules, plan choices, after posting, the three text blocks), autosave every 10 s, Save draft, Discard, Publish with a note and an Undo toast, versions list with Restore, a "Preview the saved draft" link to `/u/post-insert/?preview=1`. Server side in `src/server/layout/post-builder.ts`: admins only (`pages.edit`), publish through `adminWrite` with the `layout.publish` undo, nothing written by merely opening the tab (it starts from today's wording).
- The old `/admin/post-page/` editor still works; it learned field sets for the three new blocks.

## Not done
- The seed wording of the six steps is unchanged (a step title is required, so it cannot be empty). The risk noted in H8.38 stays: a saved title equal to the stock wording shows as saved only once something else on the step differs.
- No embedded preview: the post-ad page needs a signed-in visitor, so Preview opens the saved draft in a new tab.
- The three-step (old design) form keeps its own `post.consent.*` keys; the consent block drives the five-step form.
