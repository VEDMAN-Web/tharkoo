# H15.10 (FIX-10, E1-A5, E1-A6, E1-B2): three stale or ambiguous tests (test-only, no product change)

## Changes
- E1-A6 `tests/e2e/home-cards.e2e.ts` (H6.13): since H12.1 (#392) a category with no photo is a short coloured strip with its icon, not a 4:5 or 3:2 box. The test still checks the 4:5 / 3:2 shape of every card that has a photo, and now checks that a no-photo card is a short strip (height under 60 percent of its width), shows its icon and has its colour fill. Intent kept: never an empty grey box.
- E1-A5 `tests/e2e/home-ad-cards.e2e.ts`: the pop-out check looked for any link named "Chat", which also matched the title link of an ad titled "E2E chatflow ...". It now checks the pop-out's own Chat button (`[data-tk="pop-chat"]`, text "Chat").
- E1-B2 `tests/e2e/account-home.e2e.ts` (H7.73): H14.3 moved Available now and Live chat to Settings. The test now checks the switches are not on the home and are on Settings (`/u/account/edit-account/`). The same test then hit a second stale line hidden behind the first: an advertiser's first menu item is called "Dashboard" (still `/u/account/`), not "Home"; the test accepts either name and checks it is the current page.

## Evidence (production build of main aeb117e, both projects, 1 worker)
- Old versions of the three specs: 3 failed (account-home at 1440 and 390; home-cards at 1440), 28 passed, 3 skipped.
- New versions: 31 passed, 3 skipped, 0 failed.
- Note: the old home-ad-cards test passed on this run. E1-A5 only fails when the first Home ad is titled with "chat" in it, so the old check was order- and data-dependent. The new check cannot be confused by an ad title.
