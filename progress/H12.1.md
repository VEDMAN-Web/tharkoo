# H12.1 Public pages: layout and text placement

## Done
1. /safety/ now renders through TrustLegalPage ("Stay safe", 7 numbered section headings, all 7 paragraphs word for word, "Report a listing" link kept under the article).
2. How it works: the empty box with "Video call photo" is gone. HowItWorksView takes an optional `photo` ({src, alt}); with no picture it renders no box and the text column is the only column.
3. Tiles (Categories, Cities, Home Popular categories):
   - h714 tiles (Categories, Top cities): no photo shows a small icon tile (BlockIcon) instead of a big empty box; description clamps to 2 lines with the space always reserved; arrow pinned top-right of the text area; names never split (overflow-wrap normal, no hyphens); text area has a fixed minimum height so rows are equal height with the arrow at the same spot.
   - Home Popular categories (CSS only, home-spec.css): same clamp, arrow pin, name rules; an empty photo is now a short pastel band, not a big box.
   - State cards on /cities/: the "N ads" pill never wraps; the state name wraps instead.
4. Blog: a post with no cover is a text card (feature and grid). Every card has one "Read article" link style. Featured title weight 700.
5. Headings: site reset made many headings weight 400. Now 700 on Contact h1 and "Send us a message", Contact side cards, How it works step and safety titles (`.h714 h3`), Home "How Tharkoo works" step titles, State names, Blog featured title, StepsBlock block titles (`.tk-block h2`).
6. Section headers: Home and 404 use one pattern (title left, link right, last-baseline aligned, link drops under the title on a narrow screen). 404 "Latest ads in India" now uses it at 28 px and wraps (no more cut text).

- A very long single-word city name in a 2-column phone tile can run out of its tile (names are never broken mid-word, as asked). The tile clips it.
