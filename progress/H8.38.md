# H8.38 (A38): post-ad text 2

## Done
- The visible words of `PhotoStep`, `ContactFields`, `ReviewStep`, `PostSuccess`, `AboutYou`, `MediaTile`, `PostPreview` and `newCopy.ts` are `post.*` UI text keys now (111 new keys: `post.photo.*`, `post.tile.*`, `post.contactBox.*`, `post.aboutYou.*`, `post.reviewStep.*`, `post.success.*`, `post.previewCard.*`, `post.stepCopy.*`), editable in Menus & site text, with the same built-in words. `FormFields.tsx` holds no words.
- Words with a number or name in them use placeholders (`{limit}`, `{shown}`, `{number}`, `{percent}`, `{label}`, `{email}`, `{where}`, `{name}`, `{fee}`); "only 1 more item fits" and "only N more items fit" are two keys, so a translation does not depend on code that adds an "s".
- `CONTACT_CHOICES` carries keys, `MediaTile` keeps a state-to-key map, `nextSteps` and `previewAd` take the text function.
- `newStepCopy` and `newSuccessCopy` take the text function as their last argument (default words when none is given), and `PostWizard` hands them its own `t` (three call sites).
- "Equal to default" rule: a saved block title is no longer replaced just because it equals the stock wording. A step takes the form's own wording (About you / Contact / Review and publish) only while the whole step (title, help, back label) is still the untouched seed. See Risks.
- New static test `tests/server/ui/a38-post-text.test.ts`: parses the nine files and fails if a visible word is left in code, checks every key used exists, the old wording is the default, an override replaces it, and the step wording rules above.

## Not done
- `UPLOAD_RULES` detail lines (shared with the ad editor) and the `copy.photoRules` block text stay as they are (block text is A41).
- The block seed values in `src/components/post/copy.ts` and `src/server/layout/defaults/post.ts` are unchanged (A41 owns the seeds).

## Files changed
`src/lib/ui/text.ts`, `src/components/PostWizard.tsx` (3 call sites, not on the card's list but needed to pass `t`), `src/components/post/{PhotoStep,ContactFields,ReviewStep,PostSuccess,AboutYou,MediaTile,PostPreview}.tsx`, `src/components/post/newCopy.ts`, `tests/server/ui/a38-post-text.test.ts`, `docs/ownership/H8.38.json`, `progress/H8.38.md`.

## Risks
- This branch stacks on #325 (H8.35): `PostWizard.tsx` already has `const t = useT()` there. The PR is opened against the H8.35 branch so the diff is only this card; it retargets to main when #325 merges.
- A saved block value cannot be told from the seed when the whole step is untouched. A site whose post layout was saved with the stock values and then edited only in one of title/help/back label shows the stock title as saved (for example "Your contacts" instead of "About you"). The lasting fix is A41: stock block values empty in `defaults/post.ts`, so an empty field means "use the site text".
- The first step help still turns into the "costs N credits" line while it is the stock line; `{fee}` in a saved help comes with A41.
