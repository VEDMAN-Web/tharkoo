# H7.102 posting fee: API shape for Lane B (agreed in the first commit)

Wallet: the balance the header pill, the credits page and the post rail already show (`walletBalance`, the WalletEntry ledger). The fee is one debit on that wallet.

## Read the fee and the balance
`GET /api/wallet/posting-fee` (signed in)
```json
{ "ok": true, "data": { "fee": 30, "balance": 45, "after": 15, "short": 0, "enough": true, "creditPriceInr": 10, "mockPaymentsOn": true } }
```
- `fee` credits (admin Settings > Money, default 30), `creditPriceInr` rupees per credit (default 10).
- `short` = credits missing (0 when `enough`), `after` = balance after posting (never below 0 in the number shown: use `short`).
- Signed-out visitors: read `fee` and `creditPriceInr` from the same route without a session is not possible; use the defaults 30 and 10 in copy, or the text key.

## Publish
`POST /api/listings/{id}/submit` (unchanged request)
- Success `200`: `{ "status": "active", "charged": 30, "balance": 15 }`. `charged` is `0` for a re-publish of an ad that was already paid for (edits, pause/resume, renew are free; drafts are free).
- Not enough credits `402`:
```json
{ "ok": false, "error": { "code": "INSUFFICIENT_CREDITS", "message": "You need 18 more credits to publish.", "need": 30, "balance": 12, "fee": 30, "short": 18 } }
```
  `message` is a plain sentence (render it as is, never the code). Nothing is charged and the draft is untouched.
- Charged exactly once per ad: a double click or a retry answers `200` with `charged: 0`.
- If moderation rejects the ad, the fee is credited back automatically (a wallet entry with the reason "refund") and the owner sees it in Notifications and the credits history.

## Admin (Lane C builds it)
Settings > Money: "Ad posting fee (credits)" (default 30), "Credit price (Rs)" (default 10), "Mock payments" On/Off (default On). One helper `readMoneySettings()` in `src/server/billing/money-settings.ts` returns `{ postingFeeCredits, creditPriceInr, mockPaymentsOn }`.

## Notes
- The weekly free-ad cap does not apply while the fee is above 0 (the fee is the limit).
- Recharge (H7.103) will add credits to this same wallet through the signed mock event, so the pill updates.
