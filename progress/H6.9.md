# H6.9: Hero banner (full banner or split)

## Done
- Hero block (home page editor) has a **Layout** choice: "Split" (today's look, default) or "Full banner" (photo behind the whole hero).
- **Dark layer**: on/off switch, layer colour, opacity 0 to 80 percent. Full banner starts with no layer. Split keeps today's gradient until the switch is changed. Setting a colour or opacity turns the layer on as a flat colour.
- **Images**: desktop and phone photos (phone optional, falls back to desktop). Fit: cover or contain. Focal point: left, centre, right, top, bottom. Height: from the image shape, small, medium, large, full screen. Help text in the editor: 1920 x 640 (desktop), 1080 x 1350 (phone).
- **Text**: heading, sub-heading and search box each shown or hidden. Position side (left, centre, right) and height (top, middle, bottom). Colour light or dark. Text shadow (off by default).
- **Whole-banner link**: used only when the heading, sub-heading and search box are all hidden.
- **Editor preview**: the real hero markup in two frames, phone (390 px) and desktop (1440 px). Each frame has its own viewport, so the media queries are the real ones. Updates 250 ms after an edit.
- **Old data**: a hero saved before H6.9 (with the old `overlay` key) has none of the new fields and renders as the split hero it always was. `resolveHero()` gives it the defaults. The old `overlay` key is no longer read.
- **Images** use next/image (WebP, the existing formats) with priority on the desktop photo, eager loading with high fetch priority on the phone photo.
- Hidden heading: kept in the page as a visually hidden h1 (search engines and screen readers still get it).

## Not done
- AVIF output was not added: `next.config.ts` lists only WebP and changing it affects every image on the site. WebP is what the hero already served.
- Upload limit: the media upload accepts up to 8 MB (existing limit). The "under 2 MB" advice is in the help text only, as asked; nothing enforces it.
- The default placeholder hero photo is 960 x 880, so with "From the image shape" the full banner is about 1320 px tall at desktop width. A 1920 x 640 image gives 480 px.
- No change to seed data.

## Risks
- The editor preview uses `renderToStaticMarkup` in the browser and iframes with `sandbox=""`. Copied page styles apply to the frames.
- An old hero block's stored `overlay` value is dropped on its next save. It did not change the rendering before, so nothing visible changes.
- The phone photo now replaces the desktop photo on phones when both are set (before, both were shown, one above the other).
