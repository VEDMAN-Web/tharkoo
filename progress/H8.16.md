# H8.16 (A16): Page builder, Home tab

## Done
- `/admin/page-builder/` (admin only, `pages.edit`): tabs Home, Listing pages, Post-ad page. The two other tabs say "Coming" and link to the old editors.
- Home tab (`src/app/admin/page-builder/_home/**`): block list with Move up/down, drag handle and a Show switch per block; a field set for the 6 blocks (banner with MediaPicker, required picture description, phone picture, focus point, "the headline is part of the picture", H1 field with counter; categories count; Home ads title plus the 8 slots; How it works steps; trust bar items; latest posts); Add block; draft autosave every 10 s ("Draft saved 10 s ago"); Discard, Save draft, Publish (Ctrl S); live preview of the saved draft (laptop and phone, hidden on a phone); versions list with Restore.
- Starts from today's Home page (the D1 converter) when no format 2 draft is saved; nothing is written until the first save.
- 8 slots: pick any ad (demo ads included, Real / Demo badge, "Not live" when an ad is not active), Move up/down, Remove, Undo toast. Written through the existing `setHomeSelectionBatch` (audited there, not versioned with the page).
- Publish goes through `adminWrite` (permission, denied-words check, one audit row) and records `format` (2 when every block is a format 2 home block, otherwise 1). Undo (new `layout.publish` handler) puts the version that was live before back as the next version; refused when the page was published again since, and not offered when nothing was live before.
- Publish is refused when a visible banner has a picture without a description.
- The switch (`homeFromLayout`) is never changed by this card. It is read-only here: a note says visitors still see today's Home page while it is off.
