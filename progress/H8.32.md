# H8.32 (A32): listing pages and D3, part 1 of 2

## Done in part 1
- **D3, build and dry run only** (`src/server/content/d3-listing-copy.ts`, `scripts/migrate/d3-listing-copy.ts`). It reads the per-URL texts (UrlOverride) and Site.landings, maps each to a category page or a city/state page, and for each page prints every old source with text, the source that wins today (computed with the pages' own order), the record it would write (a published ContentItem "listingIntro" with heading, intro, questions, title and description) and the conflicts. A dry run is the default and writes nothing. `--apply --yes` writes the records (and one revision and one audit line each); a database that is not local also needs `--allow-live`, and I did not and will not use it. Pages that already have a ContentItem are never touched; a second run writes nothing. The unused Category and Location intro fields are counted, never copied.
- **The pages read the resolver behind the switch** `Site.listingCopySource`. With "legacy" (today's default) nothing changes. With "content", category pages (`/dating/`) and city or state pages (`/dating/surat/`) take heading, intro, questions, title and description from `resolveListingCopy` (content editor first, then the listing heading block, the SEO title and description templates and the built-in text).
- Tests: `a32-d3.test.ts` (8) including the check that with the switch on the resolver gives the same heading, intro, questions, title and description the old sources gave, e2e `a32-listing` (the D3 script against the local test database, then both pages with the switch on).

## The choice made for Vedant (plan default)
- D3 copies only text that is shown today, in today's order: the per-URL text beats Site.landings; on a category page Site.landings has no say in the heading, title or description; on a city page a saved SEO template heading, title or description beats Site.landings, so the landing text for that field is NOT copied and the page is listed under conflicts. Nothing is invented and nothing is deleted: the old sources stay until A50.

## Not done (part 2)

- District pages, sub-category pages and the Cities page still read their own sources (the resolver does not cover them yet).
- The URL override still decides the canonical, noindex and picture, and its title or description still wins in the page head, as today.
