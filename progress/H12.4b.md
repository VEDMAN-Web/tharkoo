# H12.4b: the chat button no longer shifts on phones, and the h7-102 toast wording

## Done
(a) Cause of the layout shift (0.006 once on Home at 390, from H12.2 #396 on), found by logging the shift entries: the up arrow of the chat column
was added to the page only when the visitor scrolled past 300 px. The column is bottom-anchored, so the bubble did not move, but the column's own box grew by the arrow and its gap, which the browser counts as a shift of the column and the bubble (about 0.006 each time).
Fix: the arrow is always in the page and only hidden (`visibility: hidden`, class `tkn-top-away`, not focusable, `aria-hidden`) until the visitor has scrolled, so its box is reserved and showing it moves nothing. `src/components/chat/SupportChat.tsx`, `src/app/globals.css`.
Not the cause (checked): the phone size of the chat button (48 px over 52 px) comes from an inline style the chat component adds; moving it into the stylesheet left the shift at the same 0.0061, so it stays as it was (tests/server/ui/h12-2-shared-layout.test.ts checks that text).
The A3 test in tests/e2e/h12-4-motion.e2e.ts is back to its original exclusion (the fixed chat wrapper only); the wider exclusion added in the H12.4 re-run is removed. A3: 15 of 15 passes in a row (before: 5 of 12 failed).
(b) tests/e2e/h7-102-money.e2e.ts waits for "Posting fee, credit price and free ads saved." (both places), the wording since H11.1.
