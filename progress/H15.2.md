# H15.2 (FIX-2, E1-A1): Report this ad works

## Cause
The report link on the ad page carried only the number at the end of the ad's address (`?ad=0352` for `demo-0352`; the page's "public id" is made from the end of the slug in `src/lib/queries.ts`). The report API finds an ad by its whole address (slug) or a stored public id, so every hyphenated address answered "That ad could not be found".

## Fix
`src/components/new/AdActions.tsx` (the new ad page) and `src/components/AdDetail.tsx` (the older page) now put the slug first in the link: `?ad=<slug>` (the public id only if there is no slug).

## Test (first: failing on main, then passing)
`tests/e2e/h15-2-report-ad.e2e.ts`: a hyphenated demo ad and an ad of a real account are reported from the ad page; the answer is 200, the thank-you shows, the report is stored against that ad, and the real ad's report shows on the admin Reports screen.
