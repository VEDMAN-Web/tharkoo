# H7.4 Live site pages in the New design (relay #63 and #66)

Branch: `haiku/h7.4-live-pages` (from main 01e0b7b, includes H7.1 shell PR #144).
All new screens sit behind the New design switch from H7.1. Off, the old pages are unchanged
(the ad page and home page only differ when `newDesignOn()` is true).

## Done
- **Home (New design)**, `src/components/new/NewHome.tsx`, used by `src/app/page.tsx` when the switch is on:
  - banner is the admin single image, with the glass headline panel beside it (no overlay on the photo);
  - glass search bar under the banner (opens the existing search pop-up, same behaviour as the header);
  - five trust pills from the shell config (`home.trust`, default five);
  - category cards: photo on top (3:2 desktop, 4:5 phone) with a pastel strip (name, short line, arrow);
    photo is the admin category photo, empty shows a gradient;
  - latest ads with the shared listing card (`AdCard`), four in a row;
  - How it works, three steps from the shell config (`home.steps`).
  When the switch is on, the published block layout (`/admin` home layout) is not drawn. See Risks.
- **Listing title band**, `src/components/new/ListingBand.tsx`, wired into
  `src/app/[category]/[location]/page.tsx` (New design only):
  - band background per city (preferred) or per category, desktop and phone image (`media.images`);
  - glass search bar inside the band; sub-category chips moved into the band (they stay under the list when the switch is off);
  - `.tk-feed` (the list column) capped at 880 px in the New design. The filter panel markup is not touched (H7.3b).
- **Ad page (New design)**, `src/components/new/NewAdDetail.tsx`, chosen in `src/app/ad/[slug]/page.tsx`:
  - gallery 420 px (300 on phones), portrait photos shown whole over a blurred copy, thumbnail strip (`NewGallery.tsx`);
  - summary, tier badge, save, trust marks, video-verified mark, about, tag sections, details, share, report, stay-safe;
  - sticky glass contact panel on desktop (hidden under 1024 px);
  - "Similar ads near you" stacked with the listing card (`AdCard`);
  - phone (under 641 px): fixed bottom bar with WhatsApp, Chat online now and Video call (only when the server offers a tour).
- **Video call**: the existing server-backed tour flow (`ContactButtons`) is used. The server still decides whether a call
  button exists (`videoTourOffer` / `assertVideoTourAllowed`), so people categories get no call button.
  A 402 (not enough coins) now shows "Coin purchases open soon. No coins were used." instead of an error (`COIN_PURCHASE_SOON`).
- **Admin editing** (Admin > Menus and footer, new section "Home page (New design)"):
  trust pills (text and colour), How it works steps (title and text), category card photos and listing band
  images per category or city (URL fields). Saved through the existing shell config save (audited, cleaned).
- **Shell config** (`src/server/site-links/shell-config-rules.ts`): `home` and `media` sections with defaults,
  cleaning, `isSafeImageUrl` (site path or https only, no quotes, spaces or brackets, so CSS `url()` is safe).
- Tests:
  - `tests/server/shell/home-config.test.ts` (11 unit tests: defaults, caps, markup strip, image URL rules, band lookup);
  - `tests/e2e/new-live-pages.e2e.ts` (home, search pop-up, band, ad page, phone bottom bar, axe on home and ad page).
- Ownership: H7.4 entry in `docs/ownership.json` gets `src/components/new/**`, `ContactButtons.tsx`,
  `shell-config-rules.ts`, the new e2e and unit test globs. JSON validated.

## Not done
- **Video call pop-up as specified** (OTP when logged out, call card with cost and balance, "Chat first (free)",
  coin packs in the pop-up, "Calling...", seller Away with "No coins were used", 3 similar sellers online, "Tell me when online").
  Only the existing tour button and the 402 message exist. Needs server work (away state, call status) that is outside this lane.
- **Seller Away / online badges** on cards and the call button (H7.5 owns the availability switch).
- **Media library picker**: the admin image fields take URLs. There is no picker that uploads from the Media library.
- **Latest ads on home** use the ranked feed, not "latest in your city".
- **Category card photos** need an admin photo per category (none exist in the catalogue today; the gradient shows).
- **Listing card width**: `.tk-feed` is capped at 880 px for every listing in the New design (the `narrow`/`medium` card-width
  setting is overridden there). Decide whether the admin card-width setting should win.
- **Screenshots**: see the "How verified" section (only what was run is listed).
- **Lighthouse and CLS**: not measured.

## Risks
- With the New design on, the admin block layout for the home page (`/admin` home blocks) is not used on the new home page.
  Blocks edited by admin on the old home will not show until the switch is turned off. Decide before production.
- Listing band: the sub-category chips are rendered inside the band only for city pages; other listing pages (search, tags, districts)
  have no band yet.
- `ContactButtons` is shared with the old design. The 402 text change applies to both designs (no old text was used for 402).
- The ad page `related` list is the ranked related set; "near you" is not yet a true distance or city filter.
