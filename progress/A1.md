# A1 Schema additions

## Done
- Listing: `demoEndedBatch`, index `{status, lastModerationAt, publishedAt}`. ListingVersion: index `{listingId, version:-1}` (not unique).
- Category and Location: `photo {mediaId, focusX, focusY, alt?}` and `band {mediaId, phoneMediaId?, focusX, focusY}` (focus 0 to 100, default 50).
- PageLayout and PageLayoutRevision: `format` 1 or 2, default 1. SiteMedia: `trashedAt`, `purgeAfter`, `phoneVariantId`, `focusX`, `focusY`.
- `blog_editor` added to STAFF_ROLE_NAMES.
- Indexes: Session `{userId, revokedAt}`, User `{status, createdAt}`, IdentityVerification `{status, createdAt}`, Payment `{status, createdAt}`, WalletEntry `{refType, createdAt}`.
- Site: `emergency`, `undoWindows`, `postModerationSince`, `homeFromLayout`, `listingCopySource`, `launchChecklist`.
- New `src/server/models/content.ts`: ContentItem and ContentRevision (append-only) with the indexes from TECH-AUDIT c6.
- `scripts/sync-admin-indexes.mjs`: dry run lists wanted and missing indexes and any repeated (listingId, version) pairs; `--apply` creates only the missing ones.

## Not done
- No reader or writer uses the new fields yet (later cards). No data was changed. AuditEvent and Report indexes belong to A3.

## NEED / questions
- Shape of `Site.launchChecklist` was not fixed in the plan: I used `{junkAdsChecked, bannerChecked, paidPostingDecided}`, each `{at, by}` or null.
- Focus values are percentages 0 to 100, centre 50.

## Risks
- Merging this builds the new indexes on the live database at the first boot (mongoose autoIndex): 11 new indexes plus the two new collections. The `{status, lastModerationAt, publishedAt}` index on listings (about 8,200 rows) is the largest.
