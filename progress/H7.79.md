# H7.79: faster /search/

## Done
- queryListings loaded and presented every matching ad on each request (8,228 in the local seed) and then cut one page out of them. It now ranks light rows (only the fields ranking, pins and the facets need), cuts the page, loads the full documents for that page only, and presents only those. The total and the facets still cover every match; the facets are counted from the light rows.
- presentRows looked up each ad's category and places with a linear search per ad; it now uses maps.
- The search page starts the result query together with the other independent queries (states, cities, areas, shell, hero, texts) instead of waiting for it first.

## Not done
- No index change: the local numbers show the database time is small; a larger live database may still want an index on the filter fields, which Opus decides.
