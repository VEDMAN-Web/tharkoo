# H8.35 (A35): post-ad text 1

## Done
- The visible words of these files are `post.*` UI text keys now, editable in Menus & site text, with the same built-in words: `PostWizard.tsx`, `post/IdCheckFirst.tsx`, `post/PayParts.tsx`, `post/NewPostParts.tsx`, `post/CategoryTiles.tsx`, `post/PickGroup.tsx` (about 150 keys: errors, selects, field labels and notes, contact choices, consent lines, review rows, step words, receipt, the Pay and publish card, tips, rail labels, pick group hints, the ID-check screens).
- The page `/u/post-insert/` wraps the wizard in the UI text provider (`post.` keys) and hands the same words to the ID-check screen. Client parts read them with `useT()`.
- `NEW_POST_TIPS`, `RAIL_LABELS` and `RAIL_MORE_LABEL` became key maps (`NEW_POST_TIP_KEYS`, `RAIL_LABEL_KEYS`, `RAIL_MORE_KEY`).
- A static test (`a35-post-text.test.ts`) parses the six files and fails if any visible word is left in code (JSX text, text attributes, loose string literals), and checks every key used exists with the old wording.
