# H6.5 UI: live video tours (request, inbox, badge, admin switch)

NOT REVIEW PLEASE: UI and display only. No ledger, escrow, auth or money logic change. One small server addition (join link in the tour list, see Files changed).

## Done
- Ad page: "Request live video tour · N coins" button (`src/components/ad/TourRequestButton.tsx`), shown only when the server's own rule allows it (`videoTourOffer`, which reuses `assertVideoTourAllowed`). People categories and off switches get no button. Signed-out visitors get a sign-in link. Server errors (insufficient coins, own ad, already open) show the server's message.
- Advertiser tour inbox on the dashboard (`src/components/vendor/TourInbox.tsx`, rendered from `Dashboard`): list, Accept and Decline for requested tours, join link for accepted tours, "Room is not set up yet" when there is no link.
- "Video verified · <date>" badge on the ad page and on listing cards when `videoVerifiedUntil` is in the future. The date shown is `videoVerifiedUntil`. `videoVerifiedUntil` is now selected into the listing presentation (`src/server/search/query.ts`) and typed on `ListingDoc`.
- Admin → Settings → Video tours (`src/app/admin/settings/video-tours/`): superadmin only. Per-category switch and coin price (1 to 100), Save per row. People categories show the switch disabled with "Not available for people listings". Categories with no kind show "Set the category kind first". Uses the admin UI kit classes and `--adm-*` table/toggle styles. Link added from the Settings page.
- Pure helpers in `src/components/ad/tourLabels.ts`, unit tests in `tests/server/tours/tour-labels.test.ts`. The ad-page offer rule is tested in `tests/server/tours/offer.test.ts`.
- E2E: `tests/e2e/tours-ui.e2e.ts` (admin screen with axe and no horizontal scroll, signed-out admin, no tour button on a people ad).

## Server change (small, not money logic)
- `VideoRoomProvider.joinUrlFor(roomId)` added (mock and daily both return null for now).
- `listTours` returns `joinUrl` for the advertiser's rows, so the join link survives a page reload. Previously it only came back from the accept response.

- The buyer's own tour status and dispute button on the dashboard (not in the list).
- Inbox rows show the ad ID only (the tour list has no ad title). Adding the title needs a server join.
