# H7.6 User panel (relay #63 and #66; replaces H6.20)

Branch: `haiku/h7.6-user-panel` (from main 01e0b7b, which includes H7.1 #144). No H6.20 branch exists, so the Discover feed is built here from the relay #62 spec.

## Done
- User panel home (New design only, behind the New design switch): left menu (Home, Saved ads, Chats, Coins and payments, Notifications, Saved search alerts, Help and support, Settings) with unread counts; coin balance chip and Buy coins link; Buy coins panel listing the real active coin packs (pay on the existing Coins page); Saved ads (this device's saved ads, real count); Your coins (real wallet balance); Help and support (real count of unread support replies); Discover ads below.
- Discover ads (`/api/discover`, shared AdCard): filters for category, city, price band and "With video"; random order fixed by a seed per visit so paging does not repeat or skip; viewer's own ads excluded; only ads the public listing pages show (queryListings); candidate pool cached 60 seconds; infinite scroll for 5 pages, then a Load more button; skeletons while loading.
- Chats (New design): the Inbox, then "More ads you may like" with the same filters and feed. The feed is never inside a thread.
- Notifications (New design): real page built from real sources only: support tickets with an unread reply, unread chat count, and recent wallet entries. Empty state when there is nothing. No notification store exists yet, so there is no mark-as-read.
- Saved search alerts (New design): lists the user's saved searches, removes one (`DELETE /api/alerts/[id]`, owner only), and saves a new one through the existing `POST /api/alerts`.
- Old design: unchanged when the switch is off. The Coming soon pages stay for the old design.

## Not done
- Coin packs cannot be bought inline on the panel; the pack cards go to the existing Coins page, where payment already works.
- Saved ads, support and settings pages still render in the old layout inside the New header (only the home, chats, notifications and alerts use the new panel frame).
- Discover pool: queryListings returns at most 100 ads per category and city, so the feed shows the newest 100 matching ads in random order, not every live ad. Price and video filters apply inside that pool.
- "Lean toward the user's city" uses the city filter only. The account does not store a home city yet.
- Chats feed on desktop sits below the list, not in a right column.
- Screenshots: `.shots/H7.6/dashboard-{390,768,1440}.png` were taken as a visitor, so the 18+ gate covers the panel. Signed-in screenshots of the panel are not done.
- Contrast was not measured with a tool; the colours follow the mockup tokens.
- Axe ran on the visitor dashboard only (390 and 1440).
