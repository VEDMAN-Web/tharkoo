# H3.9 — Dashboard

## Done
- `src/server/admin/dashboard.ts` (new): `getDashboardData(now?)` returns real database counts only: live ads (`status: "active"`), waiting for moderation (`pending`), new ads today / last 7 days / per day for 30 days (India time, drafts and deleted not counted), new users 7 days, ID checks (`pending_review`), open reports (`open`), contact reveals 7 days (from audit event `listing.contact_reveal`; `null` when none was ever logged), active promotions (`active` and not ended), live ads by category and by city (top 10, names looked up), and the number of demo ads (slug `demo-NNNN`).
