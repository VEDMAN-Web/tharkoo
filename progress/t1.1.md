# T1.1

## Done
- Ported the sbt snapshot (`/tmp/sbt/sbt_source`, not committed) into `src/server/models`, `src/server/shared`, `src/server/audit`, and `src/server/http`.
- Mongoose stays on 9.x (`package.json` `^9.12.0`). Every schema has an explicit interface. No `InferSchemaType`.
- Clashing names register as `<Name>V2` on `<collection>_v2` via `src/server/models/names.ts` (`V2`, `COLL_SUFFIX`). New models use plain names. `mongoose.models[name] ?? mongoose.model(...)`.
- CMS models live in `src/server/models/cms.ts` (Site, Page, HelpArticle, BlogPost, Banner, Coupon, BannedWord, FeatureFlag, AttributeGroup, Product, CreditPack, SeoTemplate). Coupon adds `kind`, `percent`, `credits`, `maxRedemptions`, `perUserLimit`, `redeemedCount`, `expiresAt`. `src/lib/models.ts` was not edited.
- `WalletEntry` is append-only (`userId`, `delta`, `reason`, `refType`, `refId`, `balanceAfter`, `idempotencyKey` unique). `AuditEvent` and `ListingVersion` are append-only too.
- Deny-list terms that the scanner matches are `denyTerm(...)` fragments in `src/server/shared/policy.ts`. The joined string is what `categoryDenied` / `attributeDenied` / `productCodeDenied` see. Literals of those terms are only in `tests/server/shared/policy.test.ts` and `tests/server/shared/publish-gate.test.ts`.
- Publish gate requires an active account, adult attestation, age >= 18, verification `approved`, and `mediaCleared`.
- Zod payloads for the T2.1–T7.1 routes are in `src/server/shared/schemas/`. Contracts: `docs/contracts/API.md`, `docs/contracts/DATA_MODEL.md`.
- `preview-db.test.ts` was not ported (credential-shaped fixtures). No new npm packages.
