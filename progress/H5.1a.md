# H5.1a — Report form (e2e bug 1)

BUG 1 from lane D: /submit-report/ was a placeholder, so a visitor could not report an ad.

Now: a report form on /submit-report/ (reason, optional details up to 1000 characters). POST /api/reports creates one open report, severity by reason (trafficking S0, prohibited S1, stolen media and wrong contact S2, others S3). Ad found by slug or public id. Only a hash of the reporter IP is stored. Origin check; 5 reports per IP per 15 minutes.

Checks: tests/server/reports 6/6; typecheck clean.
