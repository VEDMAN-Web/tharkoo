# H7.158 part 1: ads live 48 hours, and an ad is never shown past its end time

## Done
- The lifetime of a new, renewed or approved ad is the code constant `DEFAULT_AD_LIFETIME_HOURS = 48` (`src/lib/ads/lifetime-rules.ts`). `adLifetimeMs()` no longer reads `Site.adLifetimeHours`, so a stored 72 (the old schema default) is ignored; the field no longer has a default. There is no setting and no screen for it (Vedant, Opus #293). Ads that are live keep their end time.
- Read-time rule: the public search/listing filter (`buildFilter`) and the search box suggestions leave out an active ad whose `expiresAt` has passed (`$nor: [{ expiresAt: { $lte: now } }]`, which keeps ads with no end time), so a late cron never shows an ended ad. The ad page already answers 410.
- Words read 48: `home.utility.ticker2` ("Fresh ads, live for 48 hours"), the shell trust pill default ("Ads live for 48 hours"), the how-it-works FAQ and the Create ad help line (built from the constant).

## Not done (part 2)

- The live Page builder trust bar item and a shell config that already has the old pill text are data: they still say 72 until an admin edits them. `ENDING_SOON_MS` stays 24 hours.
