# H3.4 (editor part): generic Layout editor and Home page admin screen

## Done
- `LayoutEditor` (client): loads with `loadLayout`, block list with drag handle plus up/down buttons, visibility toggle, device chips (Both / Phone only / Desktop only), schedule (datetime-local, stored as ISO), Duplicate (copy has no id), Delete with type-to-confirm (disabled for non-deletable types), Add block (limited to `allowedTypes`, honours each type's `max`).
- Per-block forms come from a field map in `fields.ts` (client-safe copy of the block registry: defaults, limits, field kinds). Field kinds: text (counter), richText (textarea plus safe live preview built with DOMParser and an allow-list, no `dangerouslySetInnerHTML`), image (`ImagePicker`), link, number, select, boolean (`Toggle`), string list, multi-select, repeatable items (rows with drag/up/down/remove).
- All 22 block types have real forms: hero, categoryGrid, cityLinks, latestAds, featuredAds, banner, richText, faq, steps, trust, seoText, listingHeader, filters, listingFeed, districtLinks, nearbyCities, relatedCategories, postIntro, postStep, photoRules, promotionPicker, postSuccess.
- `SaveBar` (Unsaved changes, Save draft, Preview in a new tab after saving, Publish with optional note), Revisions drawer (list, Restore into the draft, then publish), success and error Notice after every action, leave-page warning when dirty.
- `/admin/homepage/` now shows the editor for `home/default` (allowed types from `typesForPage("home")`, preview link `/admin/homepage/preview/`, link "Edit SEO title & description"). Non-admins see "Only an admin can edit the home page." The old `SiteContentForm` import was removed from this page only.

## Notes

- Restore copies a version into the draft only (the service does not publish); the UI says to publish next.
- The Preview button saves the draft first, then opens `previewHref`; that route is built by the renderer part of H3.4.
