# H17.5: structured data

Done
1. BlogPosting (src/lib/seo/schema.ts `blogPostingFromPost`, used by src/app/blog/[slug]/page.tsx): `datePublished` and `dateModified` are ISO 8601 (`isoDate`: a date already in ISO form is kept, "March 3, 2026" becomes 2026-03-03, "November 2026" becomes 2026-11 so no day is invented, an unreadable date is left out, never today). `dateModified` is the post's updatedAt, else the publish date. `image` is the post's cover, else the SEO-settings default image, else the site's default share image. `author` is the post's author (Person), else the site (Organization).
2. FAQPage JSON-LD is gone from the listing pages (city, area, sub-hub and the category hub). The visible FAQ text is untouched.
3. WebPage `name` is the page's heading (its h1), not the path. The site chrome (PathChrome) writes the WebPage only for the home page (name = site name); the city, area, sub-hub, tag and category pages and the blog post write their own, named by their heading. Other pages (search, account, help and the like) no longer carry a generic WebPage with the path as name.
4. The ad page breadcrumb ends with the ad (`adJsonLdNodes`). The visible breadcrumb is not changed.
5. ItemList `numberOfItems` is the number of items written in the list (`itemListNode` no longer takes a total). Side fix on the same lines: the position of each item on page 2 and later now uses the real page size (15); it used 25 and so started at the wrong number.
6. Organization: `sameAs` comes only from the admin list (SEO settings, empty by default); the footer social links are no longer copied into it. `contactPoint` comes from the SEO settings email/phone, else the support email the site shows in its footer (no phone is invented).
7. A sample (demo) ad writes only the breadcrumb: no Offer, Product, JobPosting, Service or rating (`isSampleListing`, shared with the page's metadata). A real ad keeps its node as before. No rating or review node is written anywhere.

Not done

- Other pages do not get a WebPage with a title (there is no way to know the `<title>` from the site chrome). Say if you want them added page by page.
