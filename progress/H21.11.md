# H21.11 - the list-row pop-out covers its row

The row pop-out was narrower than the row it opens over (75 percent of the old size), so the row's edges stuck out on both sides.

## Done
- `src/components/new/pop-layout.ts`: new `rowPopBox` (and `ROW_POP_GROW_PX = 12`): left = row left minus 12, width = row width plus 24, minimum height = row height plus 24; still clamped to the window with `POP_EDGE_PX`; a row wider than the window less the edges gets the window width less the edges.
- `src/components/new/ListingPopout.tsx`: uses `rowPopBox`; grows from the row's centre as before; the photo column is 200 px, the same as the row's photo column, so the content lines up with the row underneath. The grid-card (Home) pop-out is unchanged.
- No css change was needed (the grid columns are set inline in the component).
- Tests: `tests/server/ui/h21-11-row-popout.test.ts` (the box maths), the old width checks in `h14-1b-row-popout.e2e.ts` and `h19-1-pages.e2e.ts` and the `SIZE_SHARE` text check in `h19-1-pages.test.ts` now follow the new rule (left at or before the row's left, right at or after the row's right, photo column as wide as the row's). Shots of /search/ with the pop-out open at 1440 and 1024, before and after, in `.shots/H21.11`.
