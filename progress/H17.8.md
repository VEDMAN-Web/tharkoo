# H17.8: sample ads out of Google

Vedant's decision (19 Nov, Opus #418): sample (demo) ads must not be in Google. This replaces only the part of H16.5 that made sample ad pages indexable and put them in the ads sitemap.

Done
1. Every sample (demo) ad page says `noindex, follow` (src/app/ad/[slug]/page.tsx). It no longer depends on the ad's own noindex setting or on the site switch: a sample ad is never indexable. A real ad that is set to be indexed is unchanged.
2. The ads sitemap (src/lib/seo/sitemaps.ts) lists real live ads that are set to be indexed, and no sample ad. With only sample ads the shard is empty and is still a valid sitemap (a `urlset` with no `url`).
3. The SEO "why is this page (not) indexed" explainer (src/server/seo/explain.ts) now says a sample ad is noindex,follow and left out of the sitemap.
4. Not changed on purpose: the category, city and district pages stay indexable and still show the labelled samples; sample ads work for visitors exactly as before (the Sample ad label, the retire rule, the contact note).

H16.5 tests updated (each with a comment naming this decision)
- tests/server/listings/h16-5-robots.test.ts: the sample ad page is `index false, follow true`.
- tests/server/listings/h16-5-showcase-demo.test.ts: the ads sitemap no longer lists the sample ad; the explainer says not indexable.
- tests/server/seo/explain.test.ts: the sample ad case now expects not indexable, for both values of the ad's own setting.

New: tests/server/seo/h17-8-sample-noindex.test.ts (4 tests): sample ad robots noindex,follow whatever its own setting; real ad has no noindex (SITE_NOINDEX is off in the test); ads.xml has no sample slug and still lists a real ad; with only sample ads the ads.xml is empty and valid.

Not done
- No e2e: the e2e server runs with SITE_NOINDEX on, so every page there is noindex and could not show the difference; the unit tests run with it off.

Verified: the 7 unit test files that touch this (44 tests) pass; before the change 7 of them failed.

Risks
- Sample ads already in Google's index will drop out only after Google recrawls them (noindex), and ads.xml no longer tells Google about them. Nothing to do on our side.
