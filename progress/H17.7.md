# H17.7: Help hub and How it works (Opus #412)

## Before
- When the help articles have no section (the case on the site), the Help hub drew 8 fixed placeholder tiles ("Posting an ad, 8 articles", "Log in and account, 6 articles", ...), all linking to the hub itself, and their counts added up to a claim of 50 articles that is not true. The Popular list had 5 placeholder questions, also linking to the hub.
- The How it works questions were buttons; only the open answer was in the page, so a reader without scripts and a search engine saw one answer of five.
- The Help search box had a hidden text but no name of its own on the field.

## Now
- Help hub (src/app/help/page.tsx): tiles are built from the REAL articles. With sections, one tile per section with its real article count (as before); without sections, one tile for each article (up to 12) with its title, the first sentence of the article, and a link to `/help/<article>/`. No placeholder tile or row is ever drawn. The sentence under the title says "Search the N help articles" with the real number.
- How it works (FaqList): every answer is in the page; a closed one is only `hidden`, so the first answer is open as before, a click opens another and closes the first (aria-expanded is kept).
- The Help search field is `type="search"` with `aria-label="Search help articles"`.

## Tests (first: failing on the old build, then passing)
tests/e2e/h17-7-help-how-it-works.e2e.ts (1440 and 390): every tile href is `/help/<article>/`, each different, the first three answer 200; the count text equals the number of published help articles and "50 articles" is not on the page; the search box is found by its name; no sideways scroll; axe has no serious or critical problem; on How it works all five answer panels are in the page (none empty), one is open, and clicking a question opens its answer and closes the first. Both tests fail on a build with the old code and pass on this branch (4 passed). With the existing help-page, h11-1-prices and h12-1-public-layout specs: 27 passed, 15 skipped by design.
