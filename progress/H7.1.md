# H7.1 Shared shell (relay #63)

Branches: `haiku/h7.1-shell` (part 1, PR #141, base main) and `haiku/h7.1-shell-public` (part 2, stacked on part 1).

## Done
- New design switch on Admin > Settings (superadmin only). Stored as `newDesign` on the site document, audited with before and after. Default off, on when `SITE_NOINDEX=true` (the staging host) until a value is saved. The old design returns with one click.
- Header on every public page when the switch is on: logo, pill nav (Home, Categories, Cities, How it works, Help), city picker, Log in, Post your ad. No saved or heart icon. Under 1024 px the nav becomes a burger that opens a right-hand drawer (340 px, 90vw max, glass, icon rows, Log in and Post your ad at the bottom, focus trapped, Escape closes). The drawer sits outside the header so its fixed position is not trapped by the header's backdrop filter.
- One footer on every public page: brand block, trust pills, socials, Quick links (2 columns), Top categories (empty = first six categories), compact contact rows, legal pills, adult notice. Bottom bar keeps room for the chat bubble.
- Live chat: round bubble, closed by default, bottom right. Panel `min(360px, 100vw - 32px)` with WhatsApp, Telegram and Call quick buttons (shown once set), welcome text, topic buttons, message box. Signed-in visitors open or continue an H6.21 support ticket through the existing owner endpoints (`/api/support/tickets`).
- Every header, footer and chat text, link, contact row, social link and quick button is editable: Admin > Menus and footer (header and footer), Admin > Settings > Support chat (chat).
- Back to top button sits in the same bottom-right stack.
- Plus Jakarta Sans for the New design only (`.tkn` scope). Tokens from the mockups. Glass with solid fallbacks (`@supports`, `prefers-reduced-transparency`).

- Daily migration call (NEED 2). The default is computed on read, so staging is on without it.

## NEED
1. Guest chat tickets. `SupportTicket` requires an account owner (`ownerId`) and `openTicket` takes a user id. A guest name and email or phone cannot open a ticket without a change to `src/server/support/*` and `src/server/models/support.ts`, which is outside this lane. Needed: an optional guest contact on the ticket, and a guest-safe create endpoint with rate limits. Until then guests cannot send.
2. Migration call. `ensureNewDesignSetting` is exported from `src/server/site-links/new-design.ts`. It should run from the daily cron (`src/app/api/cron/expire/route.ts`, outside this lane). Not needed for staging today because the default follows `SITE_NOINDEX`.
3. Schema. `newDesign` is not in the Site schema (`src/server/models/cms.ts`, outside this lane). Reads use lean and writes pass `strict: false`. Add the field to the schema and drop the option.
