## NEED / follow-ups
- NEED (small): src/server/models/listing.ts has `description: { required: true }`, and Mongoose refuses an empty string. An empty description is therefore stored as one space (NO_DESCRIPTION in service.ts) and nothing shows it. If you prefer a real empty value, make the field not required in the model.
- NEED (small): src/lib/ui/post-form.ts still has the old "Write at least 20 characters." rule. The wizard drops that error (`delete next.text` in validate()), so it never shows; the line can be deleted when a card covers that file.
- Interests are saved and kept through publish and edit, but nothing shows them on the public ad yet (not part of this card).
- The State list is built from the cities' state slug (title-cased, e.g. "Andhra Pradesh"), so no extra request is needed.
