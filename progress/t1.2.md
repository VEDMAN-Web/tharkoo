# T1.2

## Done
- Insert-only seed for the T1.1 V2 models: `src/server/seed/data.ts`, `src/server/seed/run.ts`, `scripts/seed-v2.ts`.
- India: 1 country, 36 states/UTs, 59 cities, 18 districts on the top 10 cities (Mumbai, Delhi, Bengaluru, Hyderabad, Ahmedabad, Chennai, Kolkata, Surat, Pune, Jaipur). Location `type` is the five-level enum (`country`, `state`, `city`, `district`, `locality`). This seed does not insert localities.
- Categories with field definitions: dating, friendship, meetups, personal-ads, jobs, wellness (spa, massage, yoga, fitness), property, vehicles, buy-and-sell, pets, education.
- Promotion products: free, top, auto-boost, super-top, highlight, new, flash, star. Amounts are INR rupees. Codes are in `ALLOWED_PRODUCT_CODES`.
- Credit packs from `DEFAULT_CREDIT_PACKS` (INR rupees). Override with env `SEED_CREDIT_PACKS` (JSON array of `{credits, price, bonus, tag, order}`).
- Feature flags: `payments-mock`, `phone-otp`, `site-noindex`, `kyc-required`.
- Every run snapshots `locations_v2`, `categories_v2`, `promotion_products`, `credit_packs_v2`, and `feature_flags_v2` into `seed_backups` before inserting. A failed snapshot inserts nothing.
- Existing natural keys are skipped (`$setOnInsert` only). A second run inserts 0.
- `seed:dry-run` / `tsx scripts/seed-v2.ts --dry-run` prints `SEED_DRY_RUN` and writes nothing, including no backup.
- `seed:rollback` / `tsx scripts/seed-v2.ts --rollback` restores the latest `seed_backups` document for batch `seed-2026-11-10`. It refuses when a listing points at a location or category that the snapshot would remove.
- Writes go to the V2 collections only. `scripts/seed.ts` is untouched.
- `assertSeedAllowed()` runs `categoryDenied`, `textDenied`, `attributeKeyDenied`, and `productCodeDenied` before any write.
