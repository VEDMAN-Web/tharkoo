# H3.2 — Block engine (models, registry, service, renderer)

**Result:** DONE. Branch `haiku/h3.2-blocks-engine`. No public page uses the engine yet.

## Done
- `src/server/models/layout.ts`: `PageLayout` (unique `{key, scope}`), `PageLayoutRevision` (append-only plugin, bulk writes locked, unique `{key, scope, version}`), `UiText`, `SiteMedia`, `ListingPin`. Exported from `src/server/models/index.ts`.
- `src/server/layout/blocks.ts`: `BLOCKS` registry for all 22 block types in ADMIN_PLAN section 3 (zod schema, defaults, pages, deletable, max). Images need alt 3 to 125 characters; links go through `safeHref`; rich text is rejected if it holds scripts, embeds, inline handlers or `javascript:` (and is passed through `safeHtml` again when rendered).
- `src/server/layout/service.ts`: `getPublished`, `getDraft`, `saveDraft`, `publish`, `restore`, `listRevisions`. admin or superadmin only. Every block is validated; ids for new blocks are made on the server (known ids are kept so reordering keeps identity); the forbidden-terms deny-list runs on every string; a draft cannot drop a non-deletable block that was already there (`listingHeader`, `listingFeed`, `postStep`); only the `promote` step can be hidden. `publish` copies draft to published, bumps the version, writes one revision, audits `layout.publish` and clears the cache tag `layout:<key>`. `restore` copies a revision into the draft. Every write is audited.
- `src/lib/layout/read.ts`: `getPageBlocks(key, scopes, now)`: first scope with a published layout, hidden blocks and blocks outside their date window removed, cached with tag `layout:<key>`; returns `null` when nothing is published.
- `src/components/blocks/`: `BlockRenderer` plus `richText`, `banner`, `faq` (FAQPage JSON-LD only because the block is rendered), `steps`, `trust`, `seoText`. Unknown types render nothing. Device classes `tk-only-mobile` / `tk-only-desktop` are defined in `blocks.css` (imported by the renderer, so no change to `globals.css`). `{category} {city} ...` are filled with the existing `fillTemplate`.
- `src/app/admin/layout-actions.ts`: server actions `loadLayout`, `saveDraftAction`, `publishAction`, `restoreAction`, `revisionsAction`.
