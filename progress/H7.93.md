# H7.93: blog cover on the blog record

## Done
- BlogPost gets three optional fields: cover (https image address), coverAlt, coverFocus (for example 60% 40%). The admin Blog editor lists them in its hint; saving refreshes the public pages.
- Blog list: the featured card and the grid cards show the cover at 16:9 with the record's focus point; a post with no cover keeps the pink gradient.
- Post page: the cover sits above the article in place of the 200 px pink placeholder band (at most 380 px high, 16:9); no cover keeps the band.
- Safe to render: only https addresses are accepted, the focus must be two percentages (default 50% 30%), alt comes from the record.
- Seed default for fresh databases only ($setOnInsert): the "Stay safe when you meet" post gets the third cover (alt "Two friends chatting over coffee in a busy cafe at dusk", focus 60% 40%). Nothing is written to a live database from code; the live post needs the three fields set in the admin Blog editor.
