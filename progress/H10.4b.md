# H10.4b: admin breadcrumb size on phones (fix for H10.4 / #388)

## Done
- `src/app/globals.css`: the public breadcrumb rule added in H10.4 now uses `:where(nav[aria-label="Breadcrumb"], .tkn-ls-crumbs) a`.
  It had a higher specificity than the admin kit rule `.adm-k-crumb a` (44 px on phones), so admin crumbs dropped to 24 px
  and `a2-kit` and `a4-kit` failed on phone-390. With `:where()` the public links keep 24 px and the admin links get their 44 px back.
- The other H10.4 additions to globals.css (`.tk-foot-cols a`) are public footer rules; the admin pages have no such element.
  The rest of H10.4 touched public files only (listing-spec.css, CitiesView, sign-in-css, post-wizard.css, motion.css).
