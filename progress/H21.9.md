- `tests/e2e/h21-9-coin-chip.e2e.ts`: the name starts with the visible text, axe `label-content-name-mismatch` finds nothing on the chip, the Buy button is still there. On a phone the chip is not in the header (the account menu shows the balances), so only the header shot is taken there.
