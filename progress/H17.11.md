# H17.11: Google Analytics 4

Measurement ID G-TRCWRYJSZ1 is public, but it is NOT in the code: it is an admin setting.

Done
1. Admin setting: Admin > Settings > "Google Analytics ID" (src/app/admin/settings/GoogleAnalyticsSetting.tsx, server src/server/settings/analytics.ts, Site field `googleAnalyticsId`). Empty by default = no tag and the plain cookie notice. Strict shape `G-` plus 4 to 20 capitals/digits, so no other text can reach a page. Written through adminWrite: admin permission (settings.edit), forbidden-terms check, audit entry with before and after, Undo for the Settings window, public cache refreshed.
2. Consent: the existing cookie notice (localStorage `nl-cookies`: `all` = Accept, `necessary` = Only necessary) now announces the choice (event `tk-cookies`). When an ID is set the notice uses Site text keys `cookie.analytics.body/accept/necessary/notice` (admin can edit) and names Google Analytics. Nothing is requested from Google before Accept; with Only necessary nothing ever loads; the choice is remembered (saved in the browser, the notice does not come back).
3. The tag (src/components/analytics/GoogleAnalytics.tsx, rules in src/lib/analytics/ga.ts): plain gtag through next/script, strategy afterInteractive, no new package. Mounted only inside the public site chrome: the admin branch of PathChrome returns before it, and tool pages (/styleguide) skip it; `gaMayLoad` also refuses /admin and /styleguide paths. Start-up: Consent Mode default denied for analytics_storage, ad_storage, ad_user_data, ad_personalization; then analytics_storage granted after Accept (ad ones stay denied); `allow_google_signals:false`, `allow_ad_personalization_signals:false`, `send_page_view:false`.
4. Page views are sent by hand: `page_location` is the origin plus the path, never the query string or hash (so ?q= never leaves), and `page_title` is the path, never an ad title.
5. Events (only these, only these fields; `safeEventParams` drops everything else and accepts only slugs/fixed words):
   - sign_up {method: email} (registration form), login {method: email|phone} (password login, code login sheet, the ad popup, phone login).
   - post_ad_start (first draft created), post_ad_published (submit succeeded).
   - contact_click {method: chat|call|whatsapp}: REAL ads only; the sample-ad branch returns before the event, Telegram is not counted.
   - ad_view {category, city}: real ads only (a sample ad sends nothing).
   - search {category, city}: only when a word was typed, and never the words.
   - save_ad (no fields).
   An event that happens just before the tag has loaded waits in a 20-item queue, only for a visitor who already accepted on a page with an ID; otherwise it is dropped.
6. CSP (report-only, next.config.ts): script-src and connect-src now allow googletagmanager.com, google-analytics.com and analytics.google.com hosts (img-src already allows https).
7. Text: /privacy/ and /cookies/ (src/content/trust.ts) now name Google Analytics: only after Accept, what it receives and never receives, the _ga cookies, Google signals and ad personalisation off, never on admin screens, Only necessary keeps it off.

- Google is never called in tests: the e2e answers every Google host with a stub; unit tests use no network.
