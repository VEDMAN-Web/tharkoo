# H21.2 — post-ad redesign: Step 2, Ad details

## Done
- New step (`DetailsStep.tsx`, `details-step.css`), field order from the design: category row with "Change", Ad title (counter /70), Description (optional, counter /5000, the server's limit), Where (City, Area), Interests, the category's other fields, then the name (and age for people ads).
- City box (`CityCombobox.tsx`): one input over the cities of every state; names that start with the typed letters first; each option shows the state; choosing a city sets state and city. `role=combobox` and `listbox`, keys up/down, Enter, Esc. Text that matches no city gives "No city called "x". Pick one from the list." Area is off until a city is chosen.
- Interests (`InterestTags.tsx`): one chip field, Enter adds, x removes, 5 at most; "Popular:" buttons come from the category's own `interests` options (none shown when the category has none). A category field with the key `interests` is no longer shown a second time.
- No "More details" step: the category's other fields sit in step 2 (2 columns from 768 px, 1 on a phone).
- Errors: validation on blur, and on Continue a "Fix N things to continue" box at the top (links to each field) takes focus; red field border and inline message. A message goes away as soon as its field is fixed. Messages are text keys (`post.v2.det.*`).
- Live preview (`DetailsPreview`): photo area, title, category / place / interest tags, "Posted by {name}"; the part being edited gets a 2 px outline and an "Editing" tag (title, place, tags, name). Computer: side column. Phone: the "Preview" button in the step strip opens the same card in the sheet (no scroll box).
- Price removed everywhere in the post flow: field, state, saving, preview, review row, `PreviewInput.price`; the preview-box footer is hidden.
- Step title "Ad details" and lead "Clear details get more replies." (text keys, used while the layout still has the stock wording).
- Support bubble visible on this step (tested).
- Tests: tests/server/ui/city-combobox.test.ts (new), tests/e2e/h21-2-details.e2e.ts (new). Helper `pickCity` in tests/e2e/helpers.ts; the 46 old `#state` / `#city` select calls now use it.
- STATUS.md: H21.1 approved, H21.2 row added.

## Also fixed
