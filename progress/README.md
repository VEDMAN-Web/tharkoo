# progress/<task-id>.md

One file per task. The agent who owns the task writes it before opening or updating the PR. Name it with the lower-case id: `progress/t0.1.md`.

```markdown
# T0.1

## Done

## Not done

## Contracts changed
None. (or list docs/contracts edits)

## Verified how
Commands and the tail of the output.

## Next
Exact steps for the next coder or for Ana. Include NEED: if blocked.
```
