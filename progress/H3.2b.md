# H3.2b — One collection for pins

Two models were registered under the name `ListingPin`: one in `src/server/models/layout.ts` (H3.2, collection `listing_pins`) and one in `src/server/ranking/pins.ts` (H3.8, collection `listingpins`). Mongoose keeps the first one loaded, so pins could have been written to either collection depending on which file loaded first.

Fix: the H3.2 model now uses the collection name `listingpins` too, so both definitions point to the same collection and have the same fields. No data exists in either yet. Cleaner follow-up (not done here): make `pins.ts` import the model from `layout.ts` and delete its own copy.

Checks: `npm run typecheck`, `npx vitest run tests/server/layout tests/server/ranking`, ownership check.
