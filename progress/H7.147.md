# H7.147: the Home switch in the Page builder

## Done
- Page builder, Home tab: a switch "Draw the Home page from the Page builder" (`Site.homeFromLayout`). It shows only when a format 2 version is published (or the switch is already on, so it can be turned off). The old read-only pink note is gone; a one-line state text sits next to the switch.
- Turning it ON asks first: "Visitors will see the published version N now." Cancel changes nothing. Turning it OFF is one click.
- `setHomeSwitch` (src/server/layout/home-builder.ts) goes through adminWrite: pages.edit (admins), one audit line ("Turned on drawing the Home page from the Page builder (version N)"), and an Undo for the settings window that puts the saved value back (record.restore). It refuses ON without a published format 2 version, does nothing when the switch already has that value, and refreshes the public pages (named "home switch").
- The switch is off by default and nothing in this card turns it on anywhere real; the tests and e2e use the local test database and switch it back off.

## Not done
- Nothing else in the Page builder changed.
