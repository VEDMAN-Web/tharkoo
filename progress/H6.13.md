# H6.13: Hero full banner by default, banner upload, hero migration, category card photos

## Done
- **A. Full banner is the default.** A hero with no layout is a full banner (one photo edge to edge, no gradient or overlay). A hero with `heroVersion` and no layout is full. Split stays selectable. Old blocks that set their own look settings (text colour, height, overlay, etc.) and have no layout keep the split hero they had.
- **B. Banner editor.** Desktop and phone images get "Choose from media library" (or "Replace"), "Upload new banner" and "Remove banner". Removing the banner leaves the plain theme colour with the heading and search still shown. Help text: "Up to 8 MB (2 MB or less loads faster). Recommended 1920 x 640 px." and "... 1080 x 1350 px.".
- **Media delete.** An image used by the Home page hero is refused with "This image is still used by the Home page hero. Remove it from the Home page hero first."
- **Upload limit** in the media service is 8 MB (`SITE_MEDIA_MAX_BYTES`).
- **C. Migration** `src/server/layout/hero-migration.ts`: converts stored home hero blocks (draft and published). A block with no layout and no look settings becomes `layout: "full"`. A block with look settings and no layout becomes `layout: "split"`. A block with a layout chosen by the user keeps it. Every converted block gets `heroVersion: 2`, so a second run changes nothing. Runs from the daily cron (`src/app/api/cron/expire/route.ts`, reported as `heroLayoutsConverted`) and from the seed (`src/server/seed/run.ts`).
- **D. Category cards.** Photo box uses aspect-ratio: 4:5 under 640 px, 3:2 from 640 px up. Image `sizes` is `(max-width: 640px) 92vw, 300px`. Optional focal point per card (centre default; top, bottom, left, right) via `data-focus` and `object-position`. Editor help: "Best size 1080 x 1350 (portrait). Desktop shows the middle part in a wider frame."
- **Hero height** follows the photo shape at the screen width (min-height from the ratio, capped at 80vh), not `aspect-ratio`, so a taller text block grows the banner instead of being clipped.
