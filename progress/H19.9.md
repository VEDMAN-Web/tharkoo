# H19.9 - Vendor payouts in more coins, with a live-rate range

## Done
- Coins: USDT (TRC20, BEP20), USDC (ERC20, BEP20), BTC, ETH, TRX, LTC. A coin is offered only when PassimPay /v2/currencies lists it (USDT TRC20/BEP20 keep the fixed H18.6 ids 71/72).
- Wallet saved only after /v2/validateaddress accepts it (fails closed if PassimPay cannot answer; skipped only when PassimPay is not configured, i.e. local dev).
- Vendor sees "You will get about X to Y COIN" before withdrawing: credits x credit price (INR) / USDT_INR_RATE (INR to USD) / live rateUsd, minus and plus 3 percent (low rounds down, high up). Rates cached 5 minutes. On failure: "Rate unavailable, the admin confirms the exact amount".
- Admin queue shows coin, network, live estimate; admin still types the final amount (field name usdtAmount kept for compatibility). Non-dollar coins need the typed amount; a missing or tiny amount leaves the payout requested (nothing sent).
- Older saved wallets (no coin) are treated as USDT.
- New: src/server/wallet/payout-coins.ts; GET /api/wallet/payouts/coins and /payouts/estimate?coins=N.
