# H7.5: post-ad and seller panel, New design (relay #63 and #66)

Branch `haiku/h7.5-post-seller` from main 01e0b7b (H7.1 shell, #144). Replaces H6.19: nothing from `haiku/h6.19-pink-panels`
is merged, only read for reuse (owner cards, owner groups, ad status, tiny-photo watermark fix).

## Done

- **Post-ad, New design (switch on).** Five steps: Category (tiles and sub-category chips), Details (city, area, title,
  text, price, nickname, age, the category's own fields), Photos (the existing photo step: several photos, videos, Cover
  and Make cover), Contact (phone, WhatsApp, Telegram), Review (summary, 72-hour note, terms and 18+ tick, Publish).
  Step rail, live preview card, tip per step. Step wording comes from the post-ad copy (admin-editable) with the same
  defaults as before. Each Continue checks and saves only its own step, so the contact is saved at step 4 only.
- **Old three-step form** is unchanged when the switch is off.
- **Seller panel, New design (switch on)** on `/u/account/` and `/u/account/ads/`: welcome, "Available now" switch, numbers
  (live ads, all-time views and clicks, coins), My ads with All, Live, In review and Ended tabs and Load more, owner
  actions (Edit, Pause, Resume, Renew when ending soon, Post again for ended ads, Delete), wallet card, profile progress
  computed from the account, the existing tour inbox.
- **Shared AdCard owner mode** (`owner` prop): status chip, the ad's own views and clicks, owner actions. The owner's own
  visits and clicks are not counted in owner mode.
- **Listing API for the panel**: `GET /api/listings` takes `group` (live, review, ended) and returns the card data,
  tab counts, all-time totals, and each ad's shown views and clicks.
- **Availability**: `vendor_presence` (switch and last activity) and `availability_settings` (hours, default 2, 1 to 24).
  Online only when the switch is on and the last activity is inside the window; otherwise Away. Calls are allowed only
  while online (`callsAllowed`); chat is never blocked. Routes: `GET/PATCH /api/availability`,
  `POST /api/availability/activity`, `GET /api/availability/status/{id}` (status only). The panel pings activity on
  interaction, at most every 5 minutes. Admin setting "Available now: Away after" on Admin > Settings (admins).
- **Price** in the listing details stage (`price`, whole rupees or null).
- **Tiny-photo watermark fix** ported from H6.19: a 1x1 photo failed the mark composite on main, which broke every
  photo upload in the e2e suite.
- **Stale test expectations corrected**: the H6.3 video-limit wording (H6.18 changed it), the photo-step URL
  (`step=photos`, works in both designs), and the owner Edit link goes to the details step.
