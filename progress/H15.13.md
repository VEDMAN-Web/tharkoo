# H15.13: three small admin fixes from E1-C

Done
- E1-C1: the Media library menu entry now uses the `media.library` permission (src/lib/admin/screens.ts), the same one the page checks, so blog_editor and seo_editor no longer see a link that opens a closed page. content_editor and the admins still see it. Uploading pictures inside their own screens is unchanged (`media.upload`).
- E1-C3: the History Export button is a plain download link (`<a href download>`), not a Next Link, so the browser no longer prefetches the export file forever and the page settles. The admin Button and PageHeader gained a `download` option for this; every other header button is unchanged.
- E1-C5: the report-only Content Security Policy now says `frame-ancestors 'self'` instead of `'none'` (next.config.ts). Choice explained: the Page builder preview frames our own pages (the draft preview and, in the Listing tab, the live public pages), so allowing one route would miss the Listing tab; `'self'` still stops every other website from framing Tharkoo, which is what `'none'` was for. It stays report-only. The E1-C console filter no longer ignores this message.
